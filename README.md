# soft_skill.md

LT「社会性って、なんだと思う？」の発表サイト。

## 起動
`start.bat` をダブルクリック → Chrome で http://localhost:5173 が開く。
（Node があれば `npx serve`、なければ Python の `http.server` で起動）

マイクと音声認識は localhost でしか動かないので、index.html を直接開かずに start.bat から起動すること。

## 操作
- ← → / スペース / スワイプ：めくる
- URL の後ろに `#12` のようにページ番号を付けると、そのページを直接開ける（めくると番号も変わる）
- M：マイク（声で球体が動き、スライドの言い終わりで自動でめくる。ネット接続が必要）
  - 声量：球体が回る・ふくらむ、背景のグラデーションが濃くなる
  - 抑揚（声の高さ）：高いと球体と上の色が持ち上がり、低いと沈む
  - アクセント（言葉の立ち上がり）：球体に波が走る／ハートが打つ／地球儀がグリッチする
- N：カンペ（右上にタイマーも出る）
- T：タイマーのスタート/一時停止（最初のスライドを進めると自動スタート）、R：リセット（停止中のみ）。持ち時間はW（ワード設定）で変更
- F：全画面
- Y：テーマ切り替え（ナイト / OZ）。選んだテーマは保存される
